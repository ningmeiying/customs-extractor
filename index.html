PDF报关底单/退税联提取工具

选择提取模式 → 上传 PDF / ZIP / RAR 自动提取 → 导出 Excel（全部在本地浏览器完成，文件不上传服务器，仅识别第一页）

⚠ 当前版本仅支持含文字层的 PDF；图片扫描件/纯图片版 PDF 无法识别（提取时会标记失败）。

1选择提取模式与字段

提取字段（可勾选/取消）

「商品英文名称/HS编码」按项号输出，格式：英文名/HS:商品编号（如 Gas Leak Detector/HS:9027100090），每个商品编号占一行（换行分隔）。

品名中英对照表（报关单为中文品名时按本表输出英文）

支持直接从 Excel 复制「中文品名 / 英文品名」两列粘贴进来（Tab 分隔也能识别）；匹配不到的品名输出报关单原文。对照表保存在本机浏览器，下次打开还在。

字段名（Excel 列名）提取规则（正则表达式，含捕获组取第一个）

选择对应模式后勾选需要的字段，上传 PDF 即自动提取。报关底单提取适用于海关报关单底单；退税联提取适用于出口退税专用联。

2上传文件（PDF / ZIP / RAR）

📄
点击选择 或拖拽 PDF / ZIP / RAR 文件到此处（支持多选）
支持 .pdf、.zip、.rar 格式；压缩包会自动解压，提取其中的 PDF
尚未选择文件（选择后自动提取）

3提取结果

颜色说明：绿色 = 字段全部提取成功；黄色 = 有字段未找到或部分缺失；红色 = 无法提取文本（该 PDF 可能是扫描件/图片版，无文字层）。
